لغة CSS وتصميم صفحات الويب

المقدمة

تُبنى صفحات الويب من ثلاث لغات أساسية: لغة HTML التي تحدد محتوى الصفحة وهيكلها من عناوين وفقرات وصور، ولغة CSS التي تتحكم في شكلها، ولغة JavaScript التي تضيف التفاعل. وبدون CSS تظهر الصفحة بنص أسود على خلفية بيضاء وبخط افتراضي، وكأنها مستند قديم.

تُعد لغة CSS (Cascading Style Sheets) أو «أوراق الأنماط المتتالية» الأداة التي تحوّل هذه الصفحة البسيطة إلى تصميم جذاب، فهي تغيّر الألوان والخطوط والمسافات وترتيب العناصر. ويناقش هذا التقرير فكرة CSS وطريقة ربطها بالصفحة وأهم خصائصها، مع أمثلة مبسطة، وتكمن أهميته في أن شكل الموقع هو أول ما يراه المستخدم ويحكم به على جودة المنصة.

عرض الموضوع

1. ما هي CSS؟

CSS لغة تنسيق تُستخدم لتحديد كيف تُعرض عناصر HTML على الشاشة. فهي لا تغيّر محتوى الصفحة، وإنما تغيّر مظهره فقط. وفكرتها الأساسية هي فصل «المحتوى» عن «الشكل»، فيمكن تغيير تصميم موقع كامل بتعديل ملف واحد دون لمس صفحات HTML.

2. كيف نربط CSS بصفحة HTML؟

الطريقةالوصفمتى تُستخدم؟
داخل العنصر (Inline)كتابة التنسيق في خاصية style داخل الوسم نفسهتعديل سريع على عنصر واحد، ولا يُنصح بها كثيراً
داخل الصفحة (Internal)وضع التنسيقات داخل وسم <style> في الصفحةالصفحات الصغيرة
ملف خارجي (External)ملف مستقل بامتداد .css يُربط بالصفحةالمواقع والمنصات، وهي الأفضل

مثال على الربط بملف خارجي، ويوضع هذا السطر داخل قسم رأس الصفحة (head):

<link rel="stylesheet" href="style.css">

3. شكل قاعدة CSS

تتكون القاعدة من محدد (Selector) يختار العنصر المراد تنسيقه، ثم أقواس تحوي أزواجاً من الخاصية (Property) والقيمة (Value):

h1 {
  color: navy;
  font-size: 32px;
}

تعني هذه القاعدة أن كل عنوان رئيسي يظهر باللون الكحلي وبحجم خط 32 بكسل، وهو ما يمثله المحدد h1. وكلمة «المتتالية» (Cascading) تعني أنه عند تعارض قاعدتين على العنصر نفسه، يحسم المتصفح الأمر حسب ترتيب القواعد ودرجة تحديدها للعنصر.

4. تغيير الألوان والخطوط

الخاصيةوظيفتهامثال
colorلون النصcolor: #1d6fb8;
background-colorلون الخلفيةbackground-color: #f3f7fb;
font-familyنوع الخطfont-family: Arial, sans-serif;
font-sizeحجم الخطfont-size: 18px;
font-weightسمك الخط (عادي أو عريض)font-weight: bold;
text-alignمحاذاة النصtext-align: center;

ويمكن كتابة اللون بثلاث طرق: بالاسم، أو بنظام الست عشري، أو بنظام RGB، كما في الأمثلة التالية على الترتيب:

color: red;
color: #1d6fb8;
color: rgb(29, 111, 184);

5. نموذج الصندوق (Box Model)

يتعامل المتصفح مع كل عنصر في الصفحة على أنه صندوق مستطيل له أربع طبقات من الداخل إلى الخارج: المحتوى (Content)، ثم الحشو الداخلي (Padding)، ثم الإطار (Border)، ثم الهامش الخارجي (Margin). وبفهم هذه الطبقات نتحكم في المسافات بين العناصر وحجمها:

.card {
  padding: 16px;
  border: 2px solid #1d6fb8;
  margin: 20px;
}

6. التخطيط والتصميم المتجاوب

تنظم CSS ترتيب العناصر على الصفحة بأدوات أهمها Flexbox لترتيب العناصر في صف أو عمود، وGrid لتقسيم الصفحة إلى شبكة من الأعمدة والصفوف. ولجعل الموقع يناسب شاشة الهاتف والحاسوب معاً نستخدم الاستعلامات الوسائطية (Media Queries)، التي تطبّق تنسيقاً مختلفاً حسب عرض الشاشة:

@media (max-width: 600px) {
  body { font-size: 16px; }
}

7. مثال مبسط متكامل

ملف style.css التالي يغيّر شكل صفحة بسيطة:

body {
  font-family: Arial, sans-serif;
  background-color: #f3f7fb;
}
h1 {
  color: #1d6fb8;
  text-align: center;
}
p {
  font-size: 18px;
  line-height: 1.8;
}

بعد ربط هذا الملف بالصفحة يصبح الخط موحداً، والخلفية فاتحة، والعنوان أزرق في المنتصف، والفقرات أكبر وأسهل في القراءة، من غير أي تعديل على كود HTML.

8. الخلاصة

CSS هي لغة الشكل والتصميم في الويب، فهي التي تعطي الصفحات ألوانها وخطوطها وترتيبها، وتجعلها مناسبة لمختلف الشاشات. ومعرفة أساسياتها، مثل الربط والمحددات والخصائص ونموذج الصندوق، تمكّن مطور المنصات الإلكترونية من بناء واجهات واضحة وجذابة وسهلة الاستخدام.
